# Contributing

このリポジトリは作者が個人利用目的で開発したものです。

Pull Request は受け付けていません。改変・拡張したい場合は、このリポジトリを fork してご自身のリポジトリで作業してください。

不具合報告や質問は Issues で受け付けますが、対応は時間があるときに行うため、回答までに時間がかかる場合があります。

This repository is developed for personal use.

Pull Requests are not accepted. If you want to modify or extend this project, please fork the repository.

Bug reports and questions are welcome via Issues, but responses may be delayed.
