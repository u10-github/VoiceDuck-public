===============================================================================
 VoiceDuck  README
===============================================================================

■ 1. はじめに

VoiceDuck は、Discord のボイスチャットに入っている間だけ、
Chrome やゲームなど、Discord 以外のアプリの音量を自動で下げる
Windows 用の常駐アプリです。

Discord 自体の音量は下げません。

本アプリは、無償提供される簡易ツールです。
利用は自己責任でお願いします。

※ アプリ名は VoiceDuck です。


===============================================================================
■ 2. 動作環境

対応OS:
  Windows 10 / Windows 11 64bit

想定環境:
  Discord デスクトップ版
  Discord.exe / DiscordCanary.exe / DiscordPTB.exe

配布形式:
  SelfContained 版

SelfContained 版は .NET ランタイムを同梱しているため、
通常は .NET 8 Desktop Runtime を別途インストールする必要はありません。


===============================================================================
■ 3. ファイル構成

展開後のフォルダには、主に以下のファイルが含まれます。

  VoiceDuck.exe

通常利用で起動するのは、このファイルです。

  VoiceDuck.App.Console.exe

こちらは確認用のコンソール版です。
通常利用では起動しなくて大丈夫です。


===============================================================================
■ 4. インストール方法

1. 配布された zip ファイルをダウンロードします。

   例:
     VoiceDuck.zip

2. zip ファイルを右クリックし、「すべて展開」を選びます。

3. 展開したフォルダを、好きな場所に置きます。

   例:
     C:\Users\<ユーザー名>\Apps\VoiceDuck

   デスクトップ上に置いても動作します。


===============================================================================
■ 5. 起動方法

展開したフォルダ内の以下のファイルをダブルクリックしてください。

  VoiceDuck.exe

初回起動時に、Windows から次のような警告が出る場合があります。

  Windows によって PC が保護されました

その場合は、配布元が分かっている場合だけ、以下の順に進めてください。

  詳細情報 → 実行

インターネットからダウンロードしたアプリは、
Windows が「知らないアプリ」と判断して警告を出すことがあります。


===============================================================================
■ 6. 基本的な使い方

VoiceDuck を起動した状態で Discord のボイスチャットに入ると、
Chrome やゲームなど、Discord 以外のアプリの音量が自動で下がります。

Discord の音量は下がりません。

Discord のボイスチャットから抜けると、
少し待ってから音量が元に戻ります。

基本的には、VoiceDuck を起動しておくだけで使えます。


===============================================================================
■ 7. タスクトレイ常駐について

VoiceDuck は常駐アプリです。

画面右上の「×」を押しても、完全には終了しません。
ウィンドウが閉じるだけで、画面右下のタスクトレイに残ります。

タスクトレイは、画面右下の時計の近くにある小さいアイコンの場所です。

  画面右下 → ^ マーク → VoiceDuck のアイコン

完全に終了したい場合は、タスクトレイのアイコンを右クリックして、
Exit を選んでください。


===============================================================================
■ 8. 終了方法

完全に終了する場合は、以下の手順で終了してください。

  画面右下 → ^ マーク → VoiceDuck アイコンを右クリック → Exit

終了時には、下がっていた音量をできるだけ元に戻してから終了します。


===============================================================================
■ 9. 設定方法

VoiceDuck の画面、またはタスクトレイのメニューから Settings を開きます。

主な設定項目は以下のとおりです。


□ Ducking Ratio

他のアプリの音量をどれくらい下げるかの設定です。

  例:
    0.30

これは「30%まで下げる」という意味です。
迷ったら、最初は 0.30 のままで大丈夫です。


□ Restore Delay

Discord のボイスチャットから抜けたあと、
何秒後に音量を戻すかの設定です。

  例:
    3

これは「3秒後に戻す」という意味です。


□ Trigger Apps

音量を下げるきっかけになるアプリです。

通常は Discord が登録されています。

  例:
    Discord.exe
    DiscordCanary.exe
    DiscordPTB.exe

通常は変更しなくて大丈夫です。


□ Exclude Apps

音量を下げたくないアプリを登録できます。

  例:
    chrome.exe

ここに登録したアプリは、
Discord 通話中でも音量が下がりません。


設定を変更したら、最後に Save を押してください。
変更をやめる場合は Cancel を押してください。


===============================================================================
■ 10. 手動操作

VoiceDuck の画面には、手動操作用のボタンがあります。


□ Force Duck

今すぐ音量を下げます。

Discord のボイスチャットに入っていなくても、
対象アプリの音量を下げられます。


□ Restore

下げた音量を元に戻します。

音量がおかしいと思った場合は、まず Restore を押してください。


===============================================================================
■ 11. スタートアップへの登録方法

PC 起動時に VoiceDuck も自動で起動したい場合は、
スタートアップフォルダにショートカットを入れます。


手順:

1. VoiceDuck.exe を右クリックします。

2. 「ショートカットの作成」を選びます。

3. キーボードで以下を押します。

     Windowsキー + R

4. 表示された画面に、以下を入力します。

     shell:startup

5. Enter を押すと、スタートアップフォルダが開きます。

6. 先ほど作成した VoiceDuck.exe のショートカットを
   スタートアップフォルダに入れます。

これで、次回から Windows 起動時に VoiceDuck が自動で起動します。

注意:
  exe 本体ではなく、ショートカットを入れるのがおすすめです。

  VoiceDuck のフォルダを移動すると、ショートカットが切れる場合があります。
  フォルダを移動した場合は、ショートカットを作り直してください。


===============================================================================
■ 12. アンインストール方法

VoiceDuck を削除したい場合は、以下の順で行ってください。

1. タスクトレイから Exit で終了します。

2. スタートアップフォルダに入れたショートカットを削除します。

   スタートアップフォルダの開き方:
     Windowsキー + R
     shell:startup

3. VoiceDuck のフォルダを削除します。


設定ファイルも削除したい場合は、以下のフォルダを削除してください。

  %APPDATA%\VoiceDuck

開き方:

  Windowsキー + R
  %APPDATA%\VoiceDuck


===============================================================================
■ 13. よくあるトラブル

□ 音量が戻らない

まず VoiceDuck の画面で Restore を押してください。

それでも戻らない場合は、Windows の音量ミキサーから手動で戻してください。

  設定 → システム → サウンド → 音量ミキサー


□ 画面が消えた

右上の「×」を押しても、VoiceDuck は終了せずタスクトレイに入ります。

画面右下の「^」マークを押して、
VoiceDuck のアイコンを探してください。


□ 完全に終了したい

タスクトレイの VoiceDuck アイコンを右クリックして、
Exit を押してください。


□ どの exe を起動すればいいかわからない

以下を起動してください。

  VoiceDuck.exe

Console と書いてある exe は、通常利用では起動しなくて大丈夫です。


□ スタートアップ登録後に起動しなくなった

VoiceDuck のフォルダを移動すると、ショートカットが切れる場合があります。

その場合は、スタートアップフォルダに入れた古いショートカットを削除し、
新しくショートカットを作り直してください。

■ 16. プライバシーポリシー

VoiceDuck は、利用者の個人情報を収集することを目的としたアプリではありません。

現在のソースコード上の設計として、
外部サーバーへ情報を送信する機能、利用状況を収集する機能、
広告・解析・トラッキングのための機能はありません。


収集しない情報:

  VoiceDuck は、以下のような情報を外部に送信しません。

  ・氏名
  ・メールアドレス
  ・Discord アカウント情報
  ・Discord の会話内容
  ・マイク音声
  ・録音データ
  ・キーボード入力内容
  ・ブラウザ閲覧履歴
  ・個人ファイルの内容
  ・位置情報
  ・利用状況の分析データ


アプリがローカルで扱う情報:

  VoiceDuck は、音量制御のために、
  PC 内で以下のような情報を参照する場合があります。

  ・実行中の音声セッション
  ・アプリのプロセス名
  ・アプリごとの現在音量
  ・ミュート状態
  ・マイク使用中のプロセス名
  ・VoiceDuck の設定内容


これらは、Discord が通話中かどうかを判定したり、
対象アプリの音量を下げたり戻したりするために使用されます。


マイク音声について:

  VoiceDuck は、マイクが使われているかどうかを判定します。

  ただし、マイク音声そのものを録音したり、保存したり、
  外部に送信したりする機能はありません。

  VoiceDuck が見るのは、基本的に
  「どのアプリがマイクを使用しているか」という状態です。


設定ファイルについて:

  VoiceDuck の設定は、利用者の PC 内に保存されます。

  保存場所の例:

    %APPDATA%\VoiceDuck\settings.json

  この設定ファイルには、音量をどれくらい下げるか、
  対象アプリ、除外アプリなどの設定が保存されます。


ログファイルについて:

  VoiceDuck は、動作確認や不具合調査のために、
  利用者の PC 内にログを保存する場合があります。

  保存場所の例:

    %APPDATA%\VoiceDuck\logs

  ログには、アプリの動作状態、音量変更、復元処理、
  エラー情報などが記録される場合があります。

  ログに、アプリのプロセス名などが含まれる可能性があります。

  ただし、ログファイルを外部に自動送信する機能はありません。

  不具合調査のためにログの共有をお願いする場合がありますが、
  その場合も共有するかどうかは利用者が判断してください。


外部通信について:

  VoiceDuck は、通常の動作において外部サーバーへデータを送信する機能を持ちません。

  アップデート確認、利用状況解析、広告表示、遠隔操作などの機能もありません。


第三者提供について:

  VoiceDuck は、利用者の情報を外部サーバーに収集していないため、
  収集した個人情報を第三者に提供することもありません。


注意事項:

  本プライバシーポリシーは、現在のソースコードと想定される動作に基づいて作成しています。

  今後、外部通信、アップデート確認、エラー送信、利用状況分析などの機能を追加する場合は、
  このプライバシーポリシーを更新します。
